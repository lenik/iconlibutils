== Name

findicon - concatener des fichiers vers la sortie standard

== Synopsis

*findicon* [_OPTION_]... [_FILE_]...

== Description

Copier chaque _FILE_ vers la sortie standard dans l'ordre.
Si _FILE_ est un tiret unique (*-*), lire l'entree standard a cette position.
Si aucun _FILE_ n'est donne, lire l'entree standard une seule fois.

*findicon* s'inspire de *cat*(1) : il ecrit la concatenation des entrees sur
la sortie standard.

== Options

*-v, --verbose*::
  Afficher chaque nom de fichier (ou ``standard input`` pour *-*) sur la
  sortie d'erreur avant de copier cette entree.
  Repeter pour des journaux plus detailles.

*-q, --quiet*::
  Supprimer les messages qui seraient affiches par *--verbose*.
  Si *--verbose* et *--quiet* sont tous deux donnes, *--quiet* l'emporte.

*-h, --help*::
  Afficher un resume d'utilisation et quitter avec succes.

*--version*::
  Afficher la version et les informations de licence, puis quitter avec succes.

== Exit status

*0*::
  Succes.

*1*::
  Une erreur s'est produite (options invalides, fichier illisible, ou erreur
  d'E/S).
