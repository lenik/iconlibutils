== Name

findicon - 파일을 표준 출력으로 이어 붙이기

== Synopsis

*findicon* [_OPTION_]... [_FILE_]...

== Description

각 _FILE_을 순서대로 표준 출력에 복사합니다.
_FILE_이 단일 대시(*-*)이면 그 위치에서 표준 입력을 읽습니다.
_FILE_이 없으면 표준 입력을 한 번 읽습니다.

*findicon*은 정신적으로 *cat*(1)과 비슷합니다. 입력의 연결을 표준 출력에
씁니다.

== Options

*-v, --verbose*::
  해당 입력을 복사하기 전에 각 파일 이름(*-*이면 ``standard input``)을 표준
  오류에 출력합니다.
  반복하면 더 자세한 로그가 됩니다.

*-q, --quiet*::
  *--verbose*가 출력할 메시지를 숨깁니다.
  *--verbose*와 *--quiet*가 모두 있으면 *--quiet*가 우선합니다.

*-h, --help*::
  사용법 요약을 출력하고 성공적으로 종료합니다.

*--version*::
  버전과 라이선스 정보를 출력하고 성공적으로 종료합니다.

== Exit status

*0*::
  성공.

*1*::
  오류가 발생했습니다(잘못된 옵션, 읽을 수 없는 파일, 또는 I/O 오류).
