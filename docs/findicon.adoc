== Name

findicon - shortcut for iconlib search

== Synopsis

*findicon* [_OPTION_]... [_pattern_]

== Description

*findicon* is a shortcut for *iconlib search*.
All arguments are forwarded to that command.

Example: *findicon cat* is the same as *iconlib search cat*.

See *iconlib*(1) for search options, patterns, and library selection.

== Options

Same as *iconlib search*, plus globals accepted by *iconlib*(1).
*--version* prints the *iconlib* version.

== Exit status

Same as *iconlib search*.
