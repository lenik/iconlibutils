== Name

iconlib - search and manage icons from installed icon libraries

== Synopsis

*iconlib* [_OPTION_]... _COMMAND_ [_ARGS_]...

== Description

*iconlib* searches installed icon libraries (tabler-icons, streamline-vectors,
heroicons, and similar), prints paths and metadata, copies icons into a
project, and can open *themestylebrowser*(1) for libraries that provide a
*.themestyles* file.

Library roots are discovered by scanning drop-in metadata **files**
(later directories and legacy path files override by name):

* *<install-prefix /usr>/share/iconlibutils/library/<name>*
* *~/.config/iconlibutils/library/<name>*

Each file is *key=value* (*name*, *type*, *path*, *title*, *license*,
*homepage*, *description*, …). Packaged *icons-<name>* packages install a
file named *<name>* there. Default *path* when omitted is
*/usr/share/icons-<name>*.

Optional legacy registries (same override semantics):

* */etc/iconlibutils/path*
* *~/.config/iconlibutils/path*

Each legacy line is: *TYPE* *NAME* *PATH*.
Only *TYPE* = *auto* is supported: the tree under *PATH* is walked for image
files.

If a *.iconlibrc* file is found by walking from the current directory toward
the filesystem root, that file's directory is the *project-dir*. Options in
*.iconlibrc* use the same flags as the global options below. Command-line
flags override the rc file.

== Global options

*-l* _LIBRARY_::
  Restrict or select libraries (repeatable).
  An unambiguous prefix of a registered library name is accepted.

*-d, --local-dir* _DIR_::
  Directory under *project-dir* where *pull* writes files (default: *icons*).

*-s, --schema* _SCHEMA_::
  Destination path recipe for *pull* (default: *n*).
  Tokens joined by */*:

  * *o* / *orig* — original relative path
  * *l* / *lib* — mapped library dirname
  * *f* / *fmt* — format (*svg*, *png*, …)
  * *n* / *name* — filename (*stem.ext*)
  * *m* / *stem* — filename stem without extension
  * *e* / *extension* — extension without the dot
  * *s* / *size* — size token or alias name
  * *v* / *variant* — style/variant (*outline*, *filled*, …), or *none*
*-m, --map* _NAME_=_DIR_::
  Map a library name to a local directory name (default: same as name).

*-v, --verbose*::
  More logging to standard error. Repeat for more detail.

*-q, --quiet*::
  Suppress informational messages.

*-h, --help*::
  Show help and exit.

*--version*::
  Print version and license information and exit.

== Commands

=== search

*iconlib* *search* [*-l*|*--long* | *-1*|*--names*] [_pattern_]

List icons matching _pattern_, ordered by relevance score (highest first).
Default output is names only.
With *--long*, print tab-separated *score*, library, name, sample path, and
formats.

For a plain English word (not a glob or */regex*), matching is enhanced with
singular/plural inflection (*python3-inflect*) and offline WordNet
(*wordnet-base*) synonyms/related senses (for example, searching *cat* can
also surface *kitty*).
Glob, regex, and empty patterns keep literal matching.

=== libraries

*iconlib* *libraries* [*-l*|*--long* | *-1*|*--names*]

List discovered icon libraries (alias: *ls*).
Default columns: name, path, whether the path directory exists.
With *--long*, also print title, license, and homepage.
With *--names*, print names only.

Discovery uses drop-in metadata files under
*/usr/share/iconlibutils/library/<name>*
(and user overlays); optional legacy */etc/iconlibutils/path* still applies.

=== which

*iconlib* *which* [*-a*] _name_

Print the preferred filesystem path for _name_.
With *-a*, print all matching paths.

=== info

*iconlib* *info* _name_

Print formats, sizes, variants, libraries, and asset paths.

=== pull

*iconlib* *pull* [*-F* _FORMAT_]... [*-S* _SIZE_]... [_pattern_]

Copy matching icon files into *project-dir*/*local-dir* using *--schema*.

*-F, --format* _FORMAT_::
  Limit to extension(s) such as *svg* or *png* (repeatable; default: all).

*-S, --size* _SIZE_::
  Limit to image size(s). Forms: *16*, *16x16*, or *medium=32x32* (alias).

=== push

*iconlib* *push* [_pattern_]

Reserved for uploading project icons to a remote library.
Not implemented yet.

=== browse

*iconlib* *browse* [_pattern_]

Run *themestylebrowser* on the first matching library that contains
*.themestyles*. Libraries without that file are skipped with a warning.

=== index

*iconlib* *index* [*-w*|*--web*] [*-F*|*--faiss*] [*-f*|*--force*]
[*-s*|*--upscale* _SIZE_] [*-o*|*--outdir* _DIR_] …

Build indexes for selected libraries (*-l*) and/or explicit
*--icons-root* trees.

*-w, --web*::
  Write an HTML preview (*index.html*, *icons.json*, assets).
  This is the default when neither *-w* nor *-F* is given.

*-F, --faiss*::
  Write a CLIP/FAISS index: *faiss.index*, *faiss.map* (*id* TAB *path*),
  and *faiss.json* (*{id: path}*).
  Each icon contributes an image vector and a filename-text vector.
  Icons are fitted onto a white canvas (*--upscale*, default *300x300*,
  aspect preserved), then embedded with CLIP at *224×224*.
  Filename tokens (*_*, *-*, …) become spaces for the text embedding.

*-f, --force*::
  Overwrite existing outputs.

*-s, --upscale* _SIZE_::
  Canvas size for FAISS preprocessing (*N* or *NxN*; default *300x300*).

*-o, --outdir* _DIR_::
  Output directory (default: *.*).

=== delete

*iconlib* *delete* _name_...

Remove all local assets under *project-dir*/*local-dir* whose filename stem
matches _name_ (every variant / size / format).

=== rename

*iconlib* *rename* _old_ _new_

Rename all local files for _old_ to _new_, preserving directory layout and
extensions.

=== copy

*iconlib* *copy* _from_ _to_

Copy all local files for _from_ to a new stem _to_.

=== ln

*iconlib* *ln* [*-s*] [*-f*] _target_ _name_

Create hard links (default) or symbolic links (*-s*) for every local file of
_target_ under the new stem _name_. *-f* replaces existing destinations.

=== make

*iconlib* *make* [*-s*|*--size* _SIZE_]... [*-F*|*--format* _FMT_]... _name_...

Derive additional local variants from an existing icon (preferring SVG
sources). At least one *-s* or *-F* is required.
Size/format directory segments in the path are rewritten when present;
otherwise a size directory is appended and/or the file extension is changed.
Rasterization uses *cairosvg* and *PIL*.

== Patterns

* (empty):: all icons
* _name_:: exact name match
* _glob_:: shell-style wildcards (*?*)
* /_regex_:: regular expression match on the icon name

== Files

*.iconlibrc*::
  Per-project options (*-l*, *-d*, *-s*, *-m*, …).

*/usr/share/iconlibutils/library/<name>*::
  Packaged library metadata file (primary discovery).

*~/.config/iconlibutils/library/<name>*::
  Per-user library metadata overlay file.

*/etc/iconlibutils/path*::
  Optional legacy system registry (*TYPE NAME PATH*).

*~/.config/iconlibutils/path*::
  Optional legacy user registry.

== Exit status

*0*::
  Success.

*1*::
  Error (not found, bad options, or *push* stub).
