== Name

findicon - 将文件串联输出到标准输出

== Synopsis

*findicon* [_OPTION_]... [_FILE_]...

== Description

按顺序将每个 _FILE_ 复制到标准输出。
若 _FILE_ 为单个短横线（*-*），则在该位置读取标准输入。
若未给出任何 _FILE_，则读取标准输入一次。

*findicon* 的设计精神类似 *cat*(1)：将输入串联后写到标准输出。

== Options

*-v, --verbose*::
  在复制该输入之前，将每个文件名（对 *-* 则为 ``standard input``）打印到
  标准错误。
  重复可输出更详细的日志。

*-q, --quiet*::
  抑制 *--verbose* 会打印的消息。
  若同时给出 *--verbose* 与 *--quiet*，以 *--quiet* 为准。

*-h, --help*::
  打印用法摘要并以成功状态退出。

*--version*::
  打印版本与许可证信息并以成功状态退出。

== Exit status

*0*::
  成功。

*1*::
  发生错误（无效选项、不可读文件，或 I/O 错误）。
