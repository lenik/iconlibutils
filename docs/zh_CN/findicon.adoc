== Name

findicon - iconlib search 的快捷命令

== Synopsis

*findicon* [_OPTION_]... [_pattern_]

== Description

*findicon* 是 *iconlib search* 的快捷方式，所有参数都会转发给该命令。

例如：*findicon cat* 等价于 *iconlib search cat*。

搜索选项、模式与库选择详见 *iconlib*(1)。

== Options

与 *iconlib search* 相同，并接受 *iconlib*(1) 的全局选项。
*--version* 打印 *iconlib* 的版本信息。

== Exit status

与 *iconlib search* 相同。
