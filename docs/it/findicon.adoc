== Name

findicon - concatena file sullo standard output

== Synopsis

*findicon* [_OPTION_]... [_FILE_]...

== Description

Copia ogni _FILE_ sullo standard output nell'ordine.
Se _FILE_ e un singolo trattino (*-*), legge lo standard input in quella
posizione.
Se non e dato alcun _FILE_, legge lo standard input una sola volta.

*findicon* e simile nello spirito a *cat*(1): scrive la concatenazione degli
input sullo standard output.

== Options

*-v, --verbose*::
  Stampa ogni nome di file (o ``standard input`` per *-*) sullo standard
  error prima di copiare quell'input.
  Ripetere per registrazioni piu dettagliate.

*-q, --quiet*::
  Sopprime i messaggi che verrebbero stampati da *--verbose*.
  Se sono dati sia *--verbose* sia *--quiet*, prevale *--quiet*.

*-h, --help*::
  Stampa un riepilogo d'uso ed esce con successo.

*--version*::
  Stampa versione e informazioni sulla licenza ed esce con successo.

== Exit status

*0*::
  Successo.

*1*::
  Si e verificato un errore (opzioni non valide, file illeggibile, o errore
  di I/O).
