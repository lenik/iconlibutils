== Name

findicon - وصل الملفات إلى الخرج القياسي

== Synopsis

*findicon* [_OPTION_]... [_FILE_]...

== Description

نسخ كل _FILE_ إلى الخرج القياسي بالترتيب.
إذا كان _FILE_ شرطة واحدة (*-*)، اقرأ الدخل القياسي في ذلك الموضع.
إذا لم يُعطَ أي _FILE_، اقرأ الدخل القياسي مرة واحدة.

يشبه *findicon* روح *cat*(1): يكتب وصل المدخلات إلى الخرج القياسي.

== Options

*-v, --verbose*::
  اطبع كل اسم ملف (أو ``standard input`` لـ *-*) إلى الخطأ القياسي قبل نسخ
  ذلك الدخل.
  كرّر لسجلات أكثر تفصيلاً.

*-q, --quiet*::
  كتم الرسائل التي يطبعها *--verbose*.
  إذا أُعطي *--verbose* و *--quiet* معاً، يفوز *--quiet*.

*-h, --help*::
  اطبع ملخص الاستخدام واخرج بنجاح.

*--version*::
  اطبع معلومات الإصدار والترخيص واخرج بنجاح.

== Exit status

*0*::
  نجاح.

*1*::
  حدث خطأ (خيارات غير صالحة، ملف غير قابل للقراءة، أو خطأ إدخال/إخراج).
