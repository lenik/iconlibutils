== Name

iconlib - البحث في مكتبات الأيقونات المثبتة وإدارتها

== Synopsis

*iconlib* [_OPTION_]... _COMMAND_ [_ARGS_]...

== Description

يبحث *iconlib* في مكتبات الأيقونات المثبتة (tabler-icons و
streamline-vectors و heroicons وما شابهها)، ويطبع المسارات والبيانات الوصفية،
وينسخ الأيقونات إلى مشروع، ويمكنه فتح *themestylebrowser*(1) للمكتبات التي
توفر ملف *.themestyles*.

تُقرأ جذور المكتبات من (تتجاوز الإدخالات اللاحقة بالاسم):

* */etc/iconlibutils/path*
* *~/.config/iconlibutils/path*

كل سطر غير فارغ وغير تعليقي هو: *TYPE* *NAME* *PATH*.
يُدعم فقط *TYPE* = *auto*: يُمشى الشجرة تحت *PATH* بحثاً عن ملفات الصور.

إذا وُجد ملف *.iconlibrc* بالصعود من الدليل الحالي نحو جذر نظام الملفات، فإن
دليل ذلك الملف هو *project-dir*. تستخدم الخيارات في *.iconlibrc* نفس الأعلام
كالخيارات العامة أدناه. أعلام سطر الأوامر تتجاوز ملف rc.

== Global options

*-l* _LIBRARY_::
  تقييد أو اختيار المكتبات (قابل للتكرار).
  تُقبل بادئة غير ملتبسة لاسم مكتبة مسجّل.

*-d, --local-dir* _DIR_::
  الدليل تحت *project-dir* حيث يكتب *pull* الملفات (الافتراضي: *icons*).

*-s, --schema* _SCHEMA_::
  وصفة مسار الوجهة لـ *pull* (الافتراضي: *n*).
  رموز موصولة بـ */*:

  * *o* / *orig* — المسار النسبي الأصلي
  * *l* / *lib* — اسم دليل المكتبة المعين
  * *f* / *fmt* — التنسيق (*svg*، *png*، …)
  * *n* / *name* — اسم الملف (*stem.ext*)
  * *m* / *stem* — جذع اسم الملف دون الامتداد
  * *e* / *extension* — الامتداد دون النقطة
  * *s* / *size* — رمز الحجم أو اسم الاسم المستعار
  * *v* / *variant* — النمط/المتغير (*outline*، *filled*، …)، أو *none*
*-m, --map* _NAME_=_DIR_::
  ربط اسم مكتبة باسم دليل محلي (الافتراضي: نفس الاسم).

*-v, --verbose*::
  المزيد من السجلات إلى الخطأ القياسي. كرّر لمزيد من التفصيل.

*-q, --quiet*::
  كتم الرسائل الإعلامية.

*-h, --help*::
  إظهار المساعدة والخروج.

*--version*::
  طباعة معلومات الإصدار والترخيص والخروج.

== Commands

=== search

*iconlib* *search* [*-l*|*--long* | *-1*|*--names*] [_pattern_]

سرد الأيقونات المطابقة لـ _pattern_، مرتبة حسب درجة الصلة (الأعلى أولاً).
الإخراج الافتراضي أسماء فقط.
مع *--long*، اطبع مفصولاً بعلامات جدولة: *score* والمكتبة والاسم ومسار عيّنة
والتنسيقات.

لكلمة إنجليزية عادية (ليست glob ولا */regex*)، تُعزَّز المطابقة بتصريف
المفرد/الجمع ومرادفات WordNet/المعاني ذات الصلة عبر *python3-pattern*
(مثلاً، البحث عن *cat* قد يُظهر أيضاً *kitty*).
أنماط glob و regex والفارغة تبقى مطابقة حرفية.

=== which

*iconlib* *which* [*-a*] _name_

طباعة مسار نظام الملفات المفضّل لـ _name_.
مع *-a*، اطبع كل المسارات المطابقة.

=== info

*iconlib* *info* _name_

طباعة التنسيقات والأحجام والمتغيرات والمكتبات ومسارات الأصول.

=== pull

*iconlib* *pull* [*-F* _FORMAT_]... [*-S* _SIZE_]... [_pattern_]

نسخ ملفات الأيقونات المطابقة إلى *project-dir*/*local-dir* وفق *--schema*.

*-F, --format* _FORMAT_::
  الاقتصار على امتداد(ات) مثل *svg* أو *png* (قابل للتكرار؛ الافتراضي: الكل).

*-S, --size* _SIZE_::
  الاقتصار على حجم/أحجام الصورة. الأشكال: *16*، *16x16*، أو *medium=32x32*
  (اسم مستعار).

=== push

*iconlib* *push* [_pattern_]

محجوز لرفع أيقونات المشروع إلى مكتبة بعيدة.
غير مُنفَّذ بعد.

=== browse

*iconlib* *browse* [_pattern_]

تشغيل *themestylebrowser* على أول مكتبة مطابقة تحتوي *.themestyles*.
تُتخطى المكتبات بلا ذلك الملف مع تحذير.

== Patterns

* (empty):: كل الأيقونات
* _name_:: مطابقة اسم دقيقة
* _glob_:: أحرف بديلة بأسلوب الصدفة (*?*)
* /_regex_:: مطابقة تعبير منتظم على اسم الأيقونة

== Files

*.iconlibrc*::
  خيارات لكل مشروع (*-l*، *-d*، *-s*، *-m*، …).

*/etc/iconlibutils/path*::
  سجل مكتبات النظام (يُبذَر بواسطة postinst الحزمة عند وجود أدلة share).

*~/.config/iconlibutils/path*::
  سجل مكتبات المستخدم.

== Exit status

*0*::
  نجاح.

*1*::
  خطأ (غير موجود، خيارات سيئة، أو مسودة *push*).
