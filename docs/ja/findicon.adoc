== Name

findicon - ファイルを標準出力へ連結する

== Synopsis

*findicon* [_OPTION_]... [_FILE_]...

== Description

各 _FILE_ を順に標準出力へコピーします。
_FILE_ が単独のハイフン（*-*）の場合、その位置で標準入力を読みます。
_FILE_ が与えられない場合、標準入力を一度だけ読みます。

*findicon* は精神的に *cat*(1) に似ており、入力の連結を標準出力へ書き出します。

== Options

*-v, --verbose*::
  その入力をコピーする前に、各ファイル名（*-* の場合は ``standard input``）を
  標準エラーへ表示します。
  繰り返すとより詳細なログになります。

*-q, --quiet*::
  *--verbose* が表示するメッセージを抑制します。
  *--verbose* と *--quiet* の両方がある場合、*--quiet* が優先されます。

*-h, --help*::
  用法の要約を表示して正常終了します。

*--version*::
  バージョンとライセンス情報を表示して正常終了します。

== Exit status

*0*::
  成功。

*1*::
  エラーが発生しました（不正なオプション、読めないファイル、または I/O
  エラー）。
